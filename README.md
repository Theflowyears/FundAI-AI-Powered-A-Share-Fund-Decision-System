# 🧠 AI 基金 1000 → 1500 挑战实验（fundai）

> 视频选题：交给 AI 1000 元，看它能否在半年内通过**买基金**做到 1500 元。
> 工作方式：**AI 不直接操作你的钱** —— 每个交易日 AI 分析股市走向并给出
> “今日建议”（默认照做即可），由你本人在支付宝/天天基金亲自执行后录入成交。
> 程序纪律：只能买卖**场外普通基金**（股票型/指数型/债券型均可），**绝不直接买卖股票**。

纯 Python 实现（核心零依赖），可选依赖 **AKShare**（`pip install akshare`）作为基金净值
数据源。数据主源为 **AKShare（场外基金净值，免费无配额）+ 智兔数服（指数，Token 已内置）**，
东财接口与本地缓存兜底。自带 Web 可视化仪表盘、SQLite 账本、每日研判时间线、AI 选基轮动、
止损止盈风控、**消息可视化人工筛选 + 算法词典学习与方向命中率（+DSH 本地搜索补全）**、回测与离线演示。

## 为什么“买基金”而不是“直接买股票”？（AI 的判断）

- 1000 元本金买个股：佣金最低 5 元/笔 + 卖出印花税 ≈ 每次 1%+ 的成本损耗，
  单票闪崩/停牌可能直接出局；且需要你每天盯盘，不符合“AI 托管式”实验。
- 宽基指数基金（如沪深300）也确实“太稳”：半年 +50% 基本需要一轮大牛市。
- 因此最优解是折中：**保持只买基金的约束**，但把进攻标的选择权交给 AI——
  进攻池：科创50（011609）、半导体芯片（008888）、证券公司（012700）、沪深300（005918）四只 C 类联接基金
  （C 类 0 申购费、持有满 7 天免赎回费、当日净值已扣销售服务费），
  AI 每日按 **20 日动量 + 主题分散**综合选出 top N 只不同板块进攻（默认 3 只，
  避免单押某一板块），大盘转弱时撤到债基（270049）+ 现金。
- 回测佐证（真实净值数据回放，**2025-11-10 → 2026-09-09 · 205 个交易日**，与实盘同规则、
  纯量化、不含消息面；统计来自网页「回测」落盘的 `data/backtest_last.json`，重跑自动更新）：
  期末 **¥1317.46（+31.7%）**、最大回撤 **11.4%**、**249 笔换手**、手续费 ¥0（全 C 类、7 天后免赎回费）。
- ⚠️ **口径警示：上面是“样本内”回放** —— `eq_base / rearm_days / 止盈线 / confidence_shrink` 等参数
  正是在同一段历史上调优出来的，只能说明过去；对未来的前瞻性有限，请勿直接外推（详见下节与文末免责声明）。

**回测口径与样本外说明**
- 想看更接近真实的视角，运行 `python app.py oos --months 12`：把回看窗口按时间切成
  **full（全窗）/ train（前段）/ test（后段）** 三段，test 用**当前固定参数**直接跑、不回头再调，
  结果打印并写入 `data/backtest_oos.json`（`source=live` 才可信，demo 仅流程演示）。
- **实测样例（真实数据，跑于 2026-09-09，见 `data/backtest_oos.json`）**：
  full（2025-10-09→2026-09-09，227 日）**+40.7%**；train（前 147 日）**+34.7%**；
  test（后 80 日，2026-05-20 起，近似样本外）**−6.3%**、回撤 10.9%。
  这段结果直白地说明：同窗调参的高收益（样本内）在后段并**没有**延续 —— 样本内数字应视为
  “这段历史上怎么走”，不是“未来会怎样”。
- 即便这样，如果参数曾在后段也被人工微调过，test 仍只算**近似样本外**；**真正的样本外验证 =
  本实验期逐日实盘**（1000 元 → 1500 元是否达成，由实验本身回答）。
- 想控制过拟合，最有效的不是继续在历史上调参，而是**少调参 + 长实盘**：默认激进档参数
  一经定稿就只作必要修正，更多交给每日实盘积累。

### ⏱ 场外基金 T+1 时间要点（建议文案里也会写明）

> **为什么是「盘后给策略」而不是「盘中」？** 场外基金一天只有一个净值、且按**当日收盘净值**成交：
> 无论你盘中还是盘后下单，成交价都是收盘价，盘中不存在“以盘中价抄底/逃顶”。而本策略的全部信号
> （指数收盘价、基金净值、20 日动量、止损止盈）也都只在**收盘后**才齐全。盘中给建议 =
> 用不完整数据做决策 + 造成“我能盘中择时”的错觉，反而更容易追涨杀跌。所以最优抉择是**盘后给策略**：
> AI 用当日完整收盘数据研判，你从容地在**下一交易日 15:00 前**执行，预期清晰、不慌。

- AI 的建议在**收盘后**生成，所以对应的成交时点永远是**下一交易日**；
- **申购**：下一交易日 15:00 前在支付宝/天天基金提交 → 按当日收盘净值成交，T+1 晚可查份额；
  15:00 后提交或逢节假日 → 顺延到再下一个交易日；
- **锁仓**：从确认日起持有满 **7 个自然日**再赎回才免惩罚费（<7 天收 1.5%；C 类第 8 天起为 0）；
- **赎回/转换**：下一交易日 15:00 前提交 → 按当日净值确认赎回；资金到账以平台为准
  （债基约 T+1，权益基金一般 T+1~T+3）。AI 换基默认走**『基金转换』**：赎回与申购**同日配对
  下单**，你在支付宝/天天基金用“转换/超级转换”一次操作完成（转出与转入同一交易时点确认），
  **没有“先赎回→等资金到账→再买”的空窗期**；仅当平台不支持该对基金转换时才退化为两步
  （先赎回 → 资金到账 → 下一交易日盘后再给买入建议）；
- **自动 T+1 确认（跟支付宝一致）**：你在支付宝/天天基金执行后，回网页「指令与成交」
  点 **“✔ 我已在支付宝/天天基金提交”** 即可；系统记入“已提交·待T+1确认”缓存，
  按你提交时间自动推算净值成交日（15:00 前=当日、15:00 后=下一交易日）与份额确认日，
  到确认日运行「立即运行今日研判」即**自动按净值确认份额入账**，无需再手动填份额/净值。
- 想先离线看效果：`python app.py demo && python app.py serve --demo`（合成数据，只读）。

## 三、AI 每天干什么（视频主线脚本）

1. **盘后复盘（量化+消息面）**：智兔拉取沪深300 日K与进攻池基金净值，计算 MA5/20/60、
   RSI、动量、量比 → 打出 **-100~+100 量化分**；同时抓取**当日市场快讯**（东财快讯，
   公开接口）做利好/利空关键词相关性过滤与情绪打分（净情绪阻尼 ±8），
   按 **量化65% + 消息35%** 合成最终评分（配置 DeepSeek Key 后可由大模型基于两者撰写研判全文）；
2. **总仓位**：合成评分 → 权益目标仓位 `eq_base + eq_slope×评分`（默认 60% + 0.5pp/分，封顶 95%）；
3. **风控层（严格止损止盈，先于一切进攻）**：
   - 单只浮亏 ≤ -8% → 【止损】清仓；单只浮盈 ≥ +10% → 【止盈】卖一半；≥ +25% → 全部落袋为安；
   - 总资产较本金亏 ≥ 15% → 【组合止损】权益 ≤ 25%；自历史峰值回撤 ≥ 10% 且评分 < 25
     → 【峰值回撤】跟踪止盈降到 25% 权益；
   - 单只止损/止盈卖出后当日仍允许按规则继续调仓（可同步经『基金转换』换入强势板块，
     不留资金空窗）；组合级风控（组合止损/峰值回撤）触发当天只防守不进攻；
   - 组合止损/峰值回撤触发后进入 **`risk.rearm_days`（默认 7 个交易日）防御冷却期**：
     期间权益目标强制 ≤25%、只减不加，避免“止损次日又追涨”的来回打脸；
     **但冷却期内若【再次触发单只止损/止盈】或【市场评分 > 50】→ 例外放行当日**，
     允许直接调仓（`risk.allow_rearm_trade=false` 可关闭此例外）；
   - 不足 7 天份额默认等解锁再卖（risk.allow_early_exit_fee=true 则付 1.5% 费强制执行）；
4. **选基**：动态进攻池（≥15 只：14 进攻 + 1 基准 + 1 债基、每周按动量重建）内按
   **20 日动量 + 主题分散**综合选出 top N 只（默认 3 只、同主题最多 1 只，避免单押某一板块）；
   持仓明显落后组合才轮动，且默认用
   **『基金转换』一步完成**（赎回+申购同日配对 → 平台一次转换，无资金到账空窗；
   `strategy.use_fund_convert=false` 可退回“先赎旧 → 到账 → 次日买新”两步走）；
   当日已止损/止盈的基金剔除出候选（尊重止损纪律，次日重新评估）；
5. **下单纪律**：T+1 生效、持有 <7 天不可赎回（1.5% 惩罚费率）、单笔 ≥10 元、金额取整到元；
6. **展示**：仪表盘顶部**大盘指数条**（上证/深成/创业板/沪深300/科创50/中证500，红涨绿跌，
   沪深300 标注“基准”；新浪→腾讯→东财三源兜底、45 秒缓存，界面轮询不烧配额）；
   资产曲线 vs ¥1500 目标线 vs 同起点沪深300、每日评分柱、消息面/风控记录、
   选基调仓历史、指令与成交台账。

## 五·五、激进/保守档位（strategy 参数，可随时改后重启）

当前为**激进档**（中性也保持 60% 权益）：`eq_base=0.60`（中性仓位）、
`eq_slope=0.005`（评分每±1分→仓位±0.5pp）、`eq_floor=0.10`、`eq_cap=0.95`、
`regime_step=0.10`（更灵敏调仓）、`bond_buy_floor=0.12`（机动现金 12%）、
`rotate_gap=0.05`（换基更勤）。
想回归稳健：把 `eq_base` 改回 `0.50`、`eq_cap` 改回 `0.92`、`bond_buy_floor` 改回 `0.20`。
注意：越激进收益弹性越大，回撤也越大，请自己接受对应风险。

**防抖/防御参数（新增）**：
- `risk.rearm_days=7`：组合止损/峰值回撤后的防御冷却**交易日数**（越大越稳，0=关闭）。
- `risk.allow_rearm_trade=true`：冷却期内允许“例外放行”——**再触发单只止损/止盈** 或
  **评分 > risk.rearm_bull_score(默认 50)** 时当日解除只防守限制、可直接调仓（改 false 则
  冷却期内一律只减不加）。
- `strategy.use_fund_convert=true`：轮动/换基走**基金转换**（赎回+申购同日配对、一次完成），
  改 false 退回两步走。
- `score_ema_enabled=false`：可选开启「评分 EMA 平滑」进一步降低换手（`score_ema_alpha`
  越大越跟手；平滑会牺牲一点趋势灵敏度，默认关闭，收益/回撤更平衡）。

## 六、动态备选基金池（任何时候 ≥15 只）

备选池是**动态调整**的，两层机制保证数量与质量：

1. **内置起步池（10 只）**：8 只进攻型权益 C 类（科创50/半导体芯片/证券/军工/通信/电子/
   人工智能/沪深300 等主题）+ 1 只沪深300基准（005918）+ 1 只债基底仓（270049 广发纯债C），
   全部 0 申购费、7 天后免赎回费；
2. **自动动态重建**（`config.json → screening`）：默认每 7 天（或点网页“🔄 立即重建备选池”/
   `python app.py refresh-pool`）从当前 **53 只候选基金**（`screening.universe`，可自行增删）里按
   **20 日动量**重选出 **top_equity=14 只进攻标的**（同主题最多 2 只），并附加规则：
   - 总数始终 **≥ min_total(15)**，不足自动用内置池补齐；
   - **当前持仓永远保留**（不会把你已持有的基金踢出池）；
   - 债基永远保留做防御（1 只）；
   - 每日例行若发现池过期/不足会自动顺延重试（智兔配额不足时次日再试）。

筛选结果存于 `data/pool_state.json`，界面「设置→动态备选基金池」可查看数量/来源/更新时间并一键重建。
想调更勤：改 `screening.refresh_days`；想换候选：编辑 `screening.universe`（代码来自
`tools/search_fund.py` 搜索 + `tools/check_fund.py` 校验）。

## 六·五、消息与进化：可视化人工筛选 + 算法学习 + 搜索补全

新增顶部页签 **「消息与进化」**，把“消息面”从黑盒变成“你看得见、能纠错、越用越懂你”的模块：

**1. 广域采集与联动**
- 多源拉取：东财快讯 + 新浪 7x24（任一失败自动跳过、全部失败才报错），去重合并；
- 每条消息自动打标（利好/利空/中性/与市场无关 + 强度），并识别命中板块主题、
  联动到备选池里对应的候选基金（消息→基金联动，筛选时直接看到“这条影响哪只基金”）。

**2. 每日人工筛选（可视化）**
- 网页逐条复核：点「重大利好/利好/中性/利空/重大利空/与市场无关」即可覆盖自动判断；
- 当天方向打标 ≥1 条后，**当日研判的消息分改用“人工消息分”**（净情绪按打标强度汇总，
  阻尼与自动分一致），研判文案会标注“消息面[人工筛选]”。

**3. 算法自我学习与进化**
- 每次打标即增量重算**学习词典**：从“你判为利好/利空的正文”里自动挖出高频、方向一致、
  且基础词典没有的新词（中文 2~6 字 n-gram，自动剪枝重叠子串与噪音）；
- 学习词叠加进**以后的自动打分**（`data/screening.db` 持久化），即“算法记住你的判断标准”；
- 网页可查看学到的词与多空样本数；删掉 `data/screening.db` 可一键重置学习。

**4. AI 自动方向研判 & 自检命中率**

## 八、开机自启与桌面快捷方式（本机已配置）

- **后台服务**：`data/fund200.db` 的仪表盘服务（http://127.0.0.1:8787）已做成无窗口后台进程
  （`fundai_start_hidden.py`，由 pythonw 运行，事件记录在 `data/server_autostart.log`）；
- **开机自启**：快捷方式已放入用户“启动”文件夹
  `…\Start Menu\Programs\Startup\fundai_serve.lnk`（登录后自动拉起）；
- **保活兜底**：Windows 计划任务 `fundai_keepalive` 每 15 分钟检查一次，服务不在就自动拉起。
  ⚠️ **必须用 `pythonw.exe`（无控制台）运行** `fundai_start_hidden.py`；切勿用
  `cmd /c python ...` 或 `fundai_start.bat` 做计划任务——否则每 15 分钟会闪一个 CMD 黑框再秒关。
  重建无窗口保活：
  `schtasks /Create /TN fundai_keepalive /SC MINUTE /MO 15 /TR "…\pythonw.exe …\fundai_start_hidden.py"`
- **桌面入口**：
  - `AI基金1000挑战1500-仪表盘.url` —— 双击直接用默认浏览器打开仪表盘；
  - `AI基金-启动后台服务.lnk` —— 双击手动启动/重启后台服务（已在运行则无动作）；
- **如何关闭自启**：删除启动文件夹里的 `fundai_serve.lnk`；
  删除计划任务：`schtasks /Delete /TN fundai_keepalive /F`；
  停后台进程：任务管理器结束 `pythonw.exe`（或先删任务再结束进程）。
