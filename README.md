# FundAI-AI-Powered-A-Share-Fund-Decision-System-
FundAI 是一个专为中国 A 股市场设计的 AI 基金智能决策系统，面向场外基金投资场景。系统每日收盘后自动运行：先从财联社、东方财富、新浪等渠道抓取并解析新闻，结合十年历史电报库与同花顺涨停情绪数据，提取事件语义、政策信号与题材热度；再融合均线、RSI、动量等技术指标，形成量化、消息、情绪三路评分。系统根据评分动态选基，并在固定基准仓位与硬性上限内生成买入、赎回或转换建议，同时执行基金级止损、均线减仓、回撤冷却等反应型风控。所有建议由用户手动在支付宝或天天基金执行，回填后系统自动记账、结算方向命中率并持续校准。项目内置完整回测框架与参数面板，十年实证覆盖牛、熊、震荡等多种 A 股市场状态。本系统仅针对 A 股场外基金，不涉及股票直投或杠杆交易。仅供学习研究，不构成投资建议。
